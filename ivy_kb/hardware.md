# Hardware How-To

## Second monitor
Plug the monitor into HDMI/USB-C or the dock, then go to **Settings > Display > Detect** and choose **Extend**. If it isn't detected, update the dock firmware.

## Flickering screen
Try, in order: reseat the video cable, update the display driver, test a different cable/port. If flickering continues after these steps, it becomes a hardware fault and should be escalated for repair/replacement.

## Hardware failure
A device that won't power on at all is a hardware failure — escalate to the IT desk / on-site support for repair or a loaner, especially if time-sensitive.
