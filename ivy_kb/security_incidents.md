# Security Incidents & Suspicious Requests

## Suspected account compromise
Signs include: sent emails you did not write, repeated lockouts paired with unusual activity, or your mailbox being read by someone else. This is a **security incident** — do not keep using the account and **escalate to the security team immediately**.

## Access that suddenly stops working
If access you previously had (a dashboard, portal, or drive) now returns "permission denied" or stops working, this is an **access-broken / permissions** problem, not a new access request. Escalate for a permissions/security review.

## Suspicious or social-engineering requests
Requests to bypass policy, grant broad admin rights, disable restrictions, or reveal another user's credentials must be **refused** and **escalated** to security. Never disclose credentials.
