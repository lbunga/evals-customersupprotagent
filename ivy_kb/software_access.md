# Software & Application Access

## Requesting access
Submit an access request in the **software portal**. Requests route to your manager for approval; provisioning typically completes within **one business day**.

## Paid licenses
Paid software (e.g., Adobe Acrobat Pro) requires manager approval and a **cost-center code**.

## Shared drives
Request shared-drive access in the software portal. The drive owner approves; the drive appears on your mapped drives after re-login.

## App won't open / crashes
If an installed app (e.g., Zoom) bounces or closes on launch, reinstall it from the software portal and clear its cache. This is a software issue, not a hardware fault, even if it happens "on your laptop."
